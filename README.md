# Resoluc Fotos

Primera versión de prueba. La aplicación de Windows crea copias en otra carpeta y no elimina originales. La web procesa archivos JPEG; la versión de escritorio admite más formatos. La conservación de todos los metadatos y HEIC debe comprobarse con fotos reales antes de su uso definitivo.

La aplicación de escritorio requiere Python con Pillow y pillow-heif para ejecutarse desde el código fuente.
