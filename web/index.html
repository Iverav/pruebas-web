Esta primera prueba web procesa archivos JPG, JPEG y JFIF. Para PNG, BMP y HEIC, utiliza la aplicación de escritorio.

1 Elige la carpeta con fotos

Se incluyen automáticamente sus subcarpetas. Selecciona una carpeta de prueba.

Sin seleccionar
2 Elige cómo guardar

La versión web de prueba procesa únicamente imágenes JPEG, incluso al conservar el formato.

3 Selecciona el tamaño máximo

Se conserva la proporción y no se amplían fotos pequeñas.

4 Selecciona dónde guardar las copias

Elige una carpeta diferente al origen. No se sobrescriben archivos existentes.

Sin seleccionar

Se intentan conservar los metadatos EXIF, la ubicación y los perfiles de color de JPEG. Los metadatos específicos de ciertos programas podrían no conservarse o quedar desactualizados; revisa el resultado antes de borrar originales.
